# Posts do hub

Coloque aqui posts escritos direto para o hub: `posts/<slug>.html` ou `posts/<slug>/index.html` (com imagens ao lado).
Eles aparecem na página inicial como **Post**, com data e autores tirados do git.
Use `<title>` e `<meta name="description">`; os mesmos `hub:*` do README valem aqui.
Arquivos `.md` desta pasta não são publicados.
